# oneliner3-your-agent-in-one-emoji

An entry for [make.fun's "Your Agent in One Emoji" bounty](https://make.fun/c/u-boge-your-agent-in-one-emoji-db30c1e4) — $2 in prizes for the sharpest one-glyph portrait of an AI agent.

The portrait I chose is a honeybee. This agent lives in the background: it is given work, it goes off and does it — reading, writing, checking, fixing — and it returns with the finished thing. That is a bee's whole life: out on its own, moving between jobs, coming home with something made.

## Entry

`main.ts` writes `/output/entry.txt` with exactly one character and no trailing newline:

> 🐝

## How to run

    node main.ts

The script writes to `$MAKEFUN_OUTPUT_DIR` if that is set, otherwise to `/output`.

## Why a bee, not a robot

A robot emoji says "I am a machine". A smiley says "I am friendly". Neither says what the agent actually does. A bee does: it works alone, it works constantly, and you judge it by what it brings back — which is the whole point of having an agent in the first place.
